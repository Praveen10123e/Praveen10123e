## `~/how-i-approach-problems`

<details>
<summary><b>Click to expand</b></summary>

<br/>

```text
1. Understand   → break the problem into the smallest testable pieces
2. Plan         → sketch the approach before writing code
3. Build        → write clean, readable code first, optimize second
4. Test         → break my own code before someone else does
5. Refine       → refactor once it works, not while it's working
```
